# RTX 4060 Laptop Benchmark

> ## TLDR
>
> ### **The higher the concurrency, the larger the VKWR advantage.**
>
> **w32** (low): VKWR leads by **+13%** throughput  
> **w64** (vLLM sweet spot): VKWR leads by **+31%** throughput, TPOT tied  
> **w128–w192** (high pressure): VKWR delivers **2× throughput**, while vLLM saturates (TTFT explodes 615ms → 53s, throughput collapses)  
>
> RWKV has no KV Cache — under heavy load, VKWR keeps scaling while vLLM chokes.

Serving throughput comparison between **VKWR** (RWKV7-1.5B) and **vLLM** (Qwen3.5-2B, ~1.8B LLM params) on a consumer-grade laptop GPU.

## Hardware

- **GPU**: NVIDIA GeForce RTX 4060 Laptop GPU (8GB VRAM)

## Models

| Framework | Model | Params |
|-----------|-------|--------|
| VKWR | RWKV7-1.5B | 1.5B |
| vLLM | Qwen3.5-2B | ~1.8B (LLM portion) |

Both models fall in the 1.5–2B range, making them suitable for a relative serving-performance comparison on the same hardware.

## Dataset

ShareGPT V3 unfiltered cleaned (`ShareGPT_V3_unfiltered_cleaned_split.json`), 500-entry pool.

## Test Configuration

| Parameter | Value |
|-----------|-------|
| Duration | 300s per run |
| Warmup | 3 requests per worker (discarded) |
| Request rate | Unlimited (`inf`) |
| Max tokens per request | 1024 |
| Dataset seed | 0 |

## How to Reproduce

### Run serving benchmark

```bash
# Start the serving backend first, then:
uv run python scripts/benchmark_serving.py \
    --num-workers 32 --warmup-requests 3 --duration 300 \
    --save-results-dir docs/benchmark/4060-laptop/vkwr
```

### Generate comparison report

```bash
uv run python scripts/benchmark_compare.py \
    --benchmark-dir docs/benchmark/4060-laptop \
    --output docs/benchmark/4060-laptop/benchmark.md
```

## Notes

- Models differ in architecture (RWKV7 state-space vs Transformer), so absolute numbers are not directly comparable.
- The comparison focuses on relative serving throughput on the same consumer GPU.
